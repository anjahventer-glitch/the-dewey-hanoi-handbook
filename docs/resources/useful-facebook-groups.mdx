# Useful Facebook Groups

Facebook is one of the best ways to find accommodation, buy and sell items, discover local events and ask for recommendations in Hanoi.

---

Great for:

- Asking questions
- Recommendations
- Buying & selling
- Local events
- General advice

## Tips

- Read the group rules before posting.
- Search the group before asking a question—many topics have already been answered.
- Be cautious when buying second-hand items and always inspect them before paying.
- If you're unsure where to find something in Hanoi, there's a good chance someone in one of these groups has already asked the same question.
